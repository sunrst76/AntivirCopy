# 📁 Программа копирования информации в несколько потоков (MultiCopyApp)

Десктопное приложение на C++ и Qt, предназначенное для быстрого и безопасного резервного копирования, синхронизации данных и антивирусных баз. Благодаря многопоточности программа позволяет существенно ускорить процесс копирования больших объемов файлов.

## ✨ Возможности (Features)

* 🚀 **Многопоточное копирование**: параллельное копирование данных в несколько независимых потоков (до 3 потоков одновременно) с визуальным отображением прогресса для каждого.
* 📅 **Встроенный планировщик**: возможность автоматического запуска копирования по расписанию (настройка режимов работы).
* 🔄 **Умная синхронизация**:
  * **Удаление несуществующих**: автоматическая очистка файлов в целевой папке, если они были удалены в источнике.
  * **Замена всех файлов**: режим принудительной перезаписи данных.
* 📦 **Архивация**: возможность автоматического сжатия скопированных данных в архив для экономии места.
* 📥 Работа в фоновом режиме: сворачивание приложения в системный трей (Tray Icon) для экономии места на экране.
* 📊 **Информативный интерфейс**: отображение текущего статуса работы и фиксация времени последней успешной синхронизации.

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: C++ (C++17 / C++20)
* **Фреймворк**: Qt (Widgets)
* **Потоки**: QThread / std::thread
* **Платформа**: Windows

## 🚀 Как запустить проект локально (Getting Started)

### Требования
* Установленный **Qt SDK** (включая Qt Widgets).
* Компилятор (MSVC / MinGW) и система сборки **CMake** или **Qmake**.

### Сборка и запуск (CMake)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта:
   ```bash
   cd MultiCopyApp
   ```
3. Создайте папку для сборки и скомпилируйте проект:
   ```bash
   mkdir build && cd build
   cmake ..
   cmake --build .
   ```
